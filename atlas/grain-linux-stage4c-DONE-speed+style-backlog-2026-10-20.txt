================= BACKLOG 1: SPEED (owner wants ~15-20 s/shot; DeepSeek analysis) =================
GRAIN (92 s) dominates -> biggest lever. Ranked:
1. BAKED GRAIN TILE (do first): ship a unit-variance grain tile (baked offline with the exact 7-tap toroidal
   spectrum, per channel) in the .so rodata; apply Y'=clip(Y + ((int8)tile[(x+ox)&M][(y+oy)&M]*sigmaLUT[Y])>>8),
   random ox,oy per shot. NO per-pixel hash, NO blur -> ~5-8 instr/pixel -> grain 92 s -> ~2-5 s. MUST be
   RAM-resident (SD thrash kills it). Sizes vs ~0.4 MB free: 256^2 Y + 128^2 Cb/Cr = 96 KB (safe); 512^2 Y +
   2x128^2 = 288 KB + scratch ~388 KB (borderline); 1024^2 = 1 MB (only if ~1 MB free + mlock). 512 tile +
   random offset is fine for ~2px grain; 256 may show repetition in flat areas.
2. COEFFICIENT-DOMAIN GRAIN = the ONLY path to 15-20 s: entropy-decode to quantized DCT coeffs, ADD the
   precomputed DCT of the spatial grain tile per 8x8 block (quantized with the shot's actual JPEG quant table),
   entropy-recode -> SKIP IDCT+FDCT+color-convert. ~23 s dec/enc -> ~8-12 s. Caveat: naive per-coeff noise is
   8x8-block-correlated/blocky; precomputing the DCT of the CONTINUOUS tile per block (then quantizing) keeps
   fine grain up to quantization; if Q is coarse the HF grain dies -> shape noise to surviving coeffs or accept a
   look change. Needs the per-shot quant tables (the decoder already has them).
3. AAN integer IDCT/FDCT (if staying spatial): shaves ~3-6 s off 23 s. Memory-neutral. After the baked tile.
4. Landing: avoid the temp->orig copy (saves ~3.5 s) — but rename is dead, so a copy or in-place overwrite is
   needed; keep sequential.
BLUNT FLOOR (DeepSeek): spatial fine grain hard floor ~25-35 s (baked tile 5 + decode 8 + encode 15 + file 3.5
= ~31.5 s; AAN -> ~25-30 s). 15-20 s NOT reachable spatially -> needs coefficient-domain. => PLAN: (a) baked
tile first (get to ~30 s, keeps the exact spatial look); (b) if 15-20 s required, move grain to the
coefficient domain (assess the blockiness/quality tradeoff on the real frames offline before committing).
