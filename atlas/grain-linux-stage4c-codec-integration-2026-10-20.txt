object, ZERO external symbols (no libc, no __aeabi_*, no float, no variable division; own udiv32 + reciprocal
quant; PC-rel R_ARM_REL32 only → no runtime fixups). Decode of DSC09580 = BITEXACT vs libjpeg/PIL (MAE 0, 0

/ jpeg_encode_arena_size / jpeg_encode; jpeg_image has comp[3] (Y/Cb/Cr) each with data/stride/width/height/pw/ph

================= THE GRAIN PASS (grain-grain.c + code/grain-shim/grain_luts.h, archived) =================
Freestanding integer film-grain on the decoded planes, implementing the locked recipe (ultramax400/0.15):
per-pixel u32 hash noise -> separable blur K=[1,4,11,16,11,4,1]/48 (luma 1 pass; chroma 2 passes = coarser)
-> plane' = clip(plane + (blur * GAIN[co-located luma]) >> 8). GAIN_Y/CB/CR[256] baked from int_grain.py
(peaks 132/110/65; cal_l=16.99, cal_c=11.96). Y/Cb/Cr use INDEPENDENT seeds (seed, +101, +202) -> decorrelated
chroma mottle. grain.o compiles `-nostdlib` with ZERO external symbols (division only by the constant 48 ->
mul+shift; the one luma/chroma ratio uses a tiny loop-idiv computed ONCE per component, not per pixel).
